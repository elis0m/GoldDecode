GoldDecode

개인정보처리방침

시행일: 2026년 6월 30일

수집하는 정보

GoldDecode는 서버가 없는 정적 웹 서비스입니다. 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

테마 설정(라이트/다크)만 브라우저 localStorage에 저장되며, 외부로 전송되지 않습니다.

외부 데이터

금 시세 데이터는 KRX Open API를 통해 GitHub Actions가 수집하여 저장소 파일로 관리합니다. 사용자 브라우저는 해당 파일을 읽을 뿐, KRX API에 직접 접속하지 않습니다.

쿠키 및 추적

쿠키, 광고 추적, 분석 도구(Google Analytics 등)를 사용하지 않습니다.

호스팅

이 서비스는 GitHub Pages를 통해 호스팅됩니다. 서버 접근 로그는 GitHub의 개인정보처리방침을 따릅니다.
