수집하는 정보

GoldDecode는 서버가 없는 정적 웹 서비스입니다. 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

서비스 이용 중 다음 정보가 사용자 기기에만 저장됩니다:

· 테마 설정 (라이트/다크) — 브라우저 localStorage에 저장, 외부 전송 없음

외부 데이터 사용

금 시세 데이터는 KRX Open API를 통해 GitHub Actions가 주기적으로 수집하여 이 저장소에 파일로 저장합니다. 사용자의 브라우저는 해당 파일을 읽을 뿐, KRX API에 직접 접속하지 않습니다.

쿠키 및 추적

GoldDecode는 쿠키, 광고 추적, 분석 도구(Google Analytics 등)를 사용하지 않습니다.

GitHub Pages 호스팅

이 서비스는 GitHub Pages를 통해 호스팅됩니다. GitHub의 서버 접근 로그(IP 주소 등)는 GitHub의 개인정보처리방침을 따릅니다.
